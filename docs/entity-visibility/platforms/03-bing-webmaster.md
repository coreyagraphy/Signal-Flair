# 03 — Bing Webmaster Tools (10 min)

Why it matters more than it sounds: **Bing's index feeds ChatGPT search and Microsoft Copilot.** For an AEO company, Bing is arguably as important as Google.

1. Go to https://www.bing.com/webmasters and sign in (any Microsoft account).
2. Choose **"Import from Google Search Console"** → import both properties (signalflair.ai, mentalvision.ai). This copies verification and sitemaps in one click.
3. Confirm both sitemaps show as processed.
4. Optional but useful: Bing → URL Submission → submit the same key URLs listed in file 02, Step 3.

Note: IndexNow (which pings Bing instantly on content changes) is already set up on signalflair.ai — key `14f9535549bc7f5b82b5a26cd4259de3` — and Claude re-pings it after every deploy. The Webmaster account gives you the dashboard to see the results.

**Done =** both sites verified in Bing Webmaster, sitemaps accepted.
